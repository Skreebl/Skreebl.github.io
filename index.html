O meu credo é pegar em problemas rotineiros complexos e construir soluções simples para eles. Trabalhando com sistemas de rega automatizados, estufas e maquinaria, habituei-me a ver como e onde o processo pode ser otimizado. Para mim não há diferença entre reparar ou criar - seja o motor de um carro ou a estrutura de uma base de dados.

A criação de aplicações web é o meu hobby, que traz benefícios reais. Não escrevo código só por escrever. Crio ferramentas leves, rápidas e fiáveis que podem ser abertas num telemóvel no meio do campo, onde se inserem os dados para obter instantaneamente o resultado, poupando horas de trabalho._
